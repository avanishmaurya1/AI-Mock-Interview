🤖 **AI Mock Interview**

AI-powered interview preparation platform that helps candidates practice real-world interviews with AI-generated questions, answer evaluation, personalized feedback, resume-based interviews, and voice-based answering.

⚙️ **Installation**

📥 1. Clone the Repository

git clone https://github.com/avanishmaurya1/AI-Mock-Interview.git
cd AI-Mock-Interview

🎨 2. Frontend Setup

cd client
npm install
npm run dev

⚙️ 3. Backend Setup

Open another terminal:

cd server
npm install
npm start
<hr>

🔑 **Environment Variables**

Create a .env file inside the server folder:

PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key

⚠️ Never commit your .env file or API keys to GitHub.

🔄 **How It Works**

1️⃣ Create an account or log in.

2️⃣ Select your Job Role.

3️⃣ Choose an Interview Type.

4️⃣ Select Experience and Difficulty.

5️⃣ Optionally upload your Resume.

6️⃣ Start the AI Mock Interview.

7️⃣ Answer using Text or Voice.

8️⃣ AI evaluates your answer and provides a Score, Feedback, Ideal Answer & Improvement Suggestions.

9️⃣ Review your complete Interview Report.
